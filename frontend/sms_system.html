Twilio Account Create பண்ணுங்க (Free)

4

Trial Limitation

Free trial-ல் only verified numbers-களுக்கு SMS போகும். Production-க்கு upgrade பண்ணினா எல்லா numbers-க்கும் போகும். (~$15/month)

5

CORS Issue Fix — Backend Proxy Use

Browser-ல் நேரடியா Twilio call பண்ண CORS block ஆகலாம். இதுக்கு ஒரு simple Node.js proxy வேணும்:

npm install express twilio cors

🖥️ Backend Server Code (Node.js)
// server.js — Run: node server.js const express = require('express'); const twilio = require('twilio'); const cors = require('cors'); const app = express(); app.use(cors()); app.use(express.json()); app.post('/send-sms', async (req, res) => { const { to, message, sid, token, from } = req.body; const client = twilio(sid, token); try { const msg = await client.messages.create({ body: message, from: from, to: '+91' + to }); res.json({ success: true, sid: msg.sid }); } catch(e) { res.json({ success: false, error: e.message }); } }); app.listen(3001, () => console.log('SMS Server: http://localhost:3001'));

உங்கோட main project-ல் இந்த server.js add பண்ணி run பண்ணுங்க. Then Trigger tab உங்கோட system-ல் work ஆகும்.

🔗 Auto-Trigger Integration Code
// உங்கோட existing website-ல் இந்த function add பண்ணுங்க async function checkAndAlertDistrict(district, riskLevel) { if (riskLevel === 'HIGH') { const agents = JSON.parse( localStorage.getItem('healthAgents') || '[]' ); const targets = agents.filter(a => a.district === district); for (const agent of targets) { await fetch('http://localhost:3001/send-sms', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ to: agent.mobile, message: `🚨 HIGH RISK ALERT!\nDistrict: ${district}\nDear ${agent.username}, immediate action required!\nLogin: yourwebsite.com`, sid: 'YOUR_TWILIO_SID', token: 'YOUR_AUTH_TOKEN', from: 'YOUR_TWILIO_NUMBER' }) }); } } } // Call this from your website when risk detected: checkAndAlertDistrict('Chennai', 'HIGH');
